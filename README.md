# Fibonacci Series in Python

A beginner-friendly Python program that demonstrates the Fibonacci sequence.

## File

* `fibonacci.py` — Contains the Fibonacci program.

## What the Program Does

The program demonstrates how to generate Fibonacci numbers using Python.

The Fibonacci sequence is a sequence in which each number is formed from the preceding numbers.

## How to Run

Make sure Python is installed on your computer.

Open a terminal in the repository directory and run:

```bash
python fibonacci.py
```

Depending on your system, you may need to use:

```bash
python3 fibonacci.py
```

## Learning Objective

This repository is intended for beginners who are learning Python. The program provides practice with the basic programming concepts used in generating the Fibonacci sequence.

## Requirements

* Python
* Basic Maths
